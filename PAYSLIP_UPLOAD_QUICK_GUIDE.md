# Quick Guide: Uploading Old Payslips

## For Administrators

### How to Upload an Old Payslip

1. **Go to Payslips Section**
   - Navigate to: Dashboard → Payslips
   - Click the **"Generate Payslip"** button

2. **Select Employee**
   - Choose the team member from the "Employee" dropdown
   - The employee ID and details will auto-fill

3. **Enter Payslip Details**
   - **Period Start:** First day of the payslip period
   - **Period End:** Last day of the payslip period  
   - **Pay Date:** Date when payment was made
   - **Salary Information:** Enter basic salary, allowances, deductions, etc.
   - **Status:** Choose "Paid" (for old/completed payslips)

4. **Upload PDF File**
   - Scroll down to **"Upload Existing Payslip PDF"** section
   - Click the upload area
   - Select your PDF file (must be PDF format, max 10MB)
   - You'll see the filename and size displayed

5. **Save the Payslip**
   - Review all information is correct
   - Click **"Save Payslip"** button
   - Wait for upload to complete

6. **Verification**
   - The payslip will appear in the list with a blue PDF icon 📄
   - Click the PDF icon to verify the file uploaded correctly
   - The employee can now see this payslip in their portal

### Important Notes

✅ **DO:**
- Use PDF files in the same format as your generated payslips
- Verify the employee is selected before uploading
- Ensure the period dates match the PDF content
- Check file size is under 10MB
- Mark as "Paid" status for historical payslips

❌ **DON'T:**
- Upload files larger than 10MB
- Upload non-PDF files (images, Word docs, etc.)
- Forget to select the employee first
- Upload without checking the dates

### File Requirements

- **Format:** PDF only
- **Size:** Maximum 10MB
- **Naming:** Use clear names (e.g., "Payslip_Jan_2023.pdf")
- **Content:** Should match the format of system-generated payslips

## For Employees

### How to View Your Uploaded Payslips

1. **Go to My Payslips**
   - Navigate to: Dashboard → My Payslips

2. **Find Your Payslip**
   - Use the month navigation arrows
   - Or use the search box to filter

3. **View PDF**
   - Look for the blue PDF icon 📄 in the payslip row
   - Click the PDF icon
   - The payslip will open in a new browser tab

4. **Download (if needed)**
   - Right-click on the opened PDF
   - Select "Save As" or "Download"

### What You'll See

- 📄 **Blue PDF Icon:** Means your admin uploaded an old payslip PDF
- **"PDF" Button:** Means you can preview a system-generated payslip
- **Download Icon:** Download the payslip as PDF

## Quick Troubleshooting

### "Only PDF files are allowed"
**Problem:** You're trying to upload a non-PDF file  
**Solution:** Convert your file to PDF format first

### "File size must be less than 10MB"
**Problem:** Your PDF is too large  
**Solution:** Compress the PDF using online tools or PDF software

### "Please select an employee first"
**Problem:** No employee selected  
**Solution:** Choose an employee from the dropdown before uploading

### PDF won't open
**Problem:** Browser blocking popup or PDF viewer issue  
**Solution:** 
- Allow popups for this site
- Try a different browser (Chrome, Firefox, Edge)
- Check if PDF viewer plugin is enabled

### Can't see uploaded payslip
**Problem:** Payslip not appearing after upload  
**Solution:**
- Refresh the page (F5)
- Check if you selected the correct month
- Verify the payslip was saved successfully

## Tips for Best Results

1. **Organize First:** Gather all old payslip PDFs before starting
2. **Consistent Naming:** Use clear, consistent file names
3. **One at a Time:** Upload one payslip at a time to avoid errors
4. **Double Check:** Verify dates and amounts match the PDF
5. **Test View:** Always click the PDF icon to verify it uploaded correctly
